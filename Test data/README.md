# نمونه اسناد تستی سامانه ترازبان هوشمند (Test Dataset)
این پوشه شامل تصاویر نمونه اسناد مالی و انباری جهت تست ۵ لایه ممیزی سامانه ترازبان است:
- **اسناد ۰۱ تا ۰۳:** پرونده شرکت پاکشو (`PO-2026-101`) شامل فاکتور، قبض انبار استاندارد و قبض انبار دارای عدد خط‌خورده و دست‌خط انباردار.
- **سند ۰۴:** نمونه سند حسابداری ۸ رقمی شرکت افق کوروش جهت تست یادگیری خودکار الگوی حسابداری در تب «الگوی سند».
- **اسناد ۰۵ تا ۰۷:** پرونده شرکت پخش سراسری گلرنگ (`PO-2026-500`) جهت تست ساخت خودکار مرجع از تصویر سفارش خرید و ممیزی سه‌جانبه.
