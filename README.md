# ترازبان هوشمند (TarazBan AI)
### سامانه هوشمند ممیزی، تطبیق سه‌جانبه اسناد مالی (3-Way Matching) و صدور خودکار سند حسابداری (On-Premise)

**ترازبان هوشمند (TarazBan AI)** یک ماژول مکمل ERP (طراحی‌شده ویژه یکپارچه‌سازی با راهکارهای مالی **گلرنگ سیستم** و شرکت‌های تولیدی، پخش مویرگی و فروشگاهی گروه صنعتی گلرنگ) است که فرآیند تطبیق سه‌جانبه بین **سفارش خرید (PO)**، **قبض رسید انبار (GRN)** و **صورتحساب رسمی فروشنده (Invoice)** را به صورت ۱۰۰٪ محلی (On-Premise) و بدون خروج داده‌های محرمانه مالی از شبکه سازمان خودکارسازی می‌کند.

## معماری ۵ لایه انحصاری (5-Layer Enterprise Architecture)

برخلاف اسکریپت‌های ساده مبتنی بر پرامپت یا ابزارهای OCR سنتی، «ترازبان هوشمند» از یک معماری ۵ لایه ترکیبی بهره می‌برد:

```text
[تصاویر اسناد: صورتحساب فروشنده + قبض رسید انبار + سفارش خرید مرجع]
       │
       ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ لایه ۱: استخراج بینایی و احراز اصالت فیزیکی سند (Vision & Authenticity) │
│ • خوانش جداول، اعداد خط‌خورده و دست‌خط انباردار با مدل محلی Qwen3.5-4B    │
│ • کنترل وجود مهر رسمی، امضای مجاز و تشخیص خودکار جابه‌جایی اسناد (Swap) │
└──────────────────────────────────────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ لایه ۲: موتور خوداصلاح‌گر ریاضی خطای دیداری (Math-Guided OCR Solver)     │
│ • حل معادله ماتریسی جمع ردیف‌ها و جمع خالص فاکتور در هسته پایتون         │
│ • کشف و اصلاح خودکار خطاهای چشمی ارقام مشابه فارسی (مثلاً ۱۲,۵۰۰ ⬅ ۱۳,۵۰۰)│
└──────────────────────────────────────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ لایه ۳: گراف حافظه خودآموز کدینگ کالا (Self-Learning Vendor Alias DB)    │
│ • تطبیق معنایی عناوین تجاری فروشندگان با کدینگ رسمی کالا در ERP (SKU)   │
│ • ذخیره دائمی تاییدیه‌های کارشناس و بازیابی آنی در ۰.۰۰۱ ثانیه           │
└──────────────────────────────────────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ لایه ۴: موتور کشف تقلب، تکرار صورتحساب و ریسک تامین‌کننده (Fraud Engine) │
│ • رهگیری امضای دیجیتال تصویر (SHA-256) جهت جلوگیری از دوبار پرداخت       │
│ • تشخیص عدم انطباق شماره پرونده مرجع با اسناد بارگذاری‌شده               │
└──────────────────────────────────────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────────────────────────────────────┐
│ لایه ۵: موتور یادگیرنده الگوی سند حسابداری شرکت (Adaptive Voucher)      │
│ • یادگیری کدینگ معین/تفصیلی اختصاصی هر شرکت از روی تصویر نمونه سند      │
│ • صدور خودکار سند حسابداری دوبل تراز (بدهکار = بستانکار) + خروجی JSON/PDF│
└──────────────────────────────────────────────────────────────────────────┘
```

## قابلیت‌های کلیدی نسخه MVP

1. **تطبیق معنایی هوشمند (Semantic SKU Matching):** تشخیص هم‌معنایی عناوین تجاری متفاوت در فاکتور تامین‌کننده (مانند *«ظرف پلاستیکی ۲۵۰ میلی‌لیتر بی‌رنگ»*) با کدینگ رسمی انبار در ERP (مانند *«بطری پت ۲۵۰ سی‌سی شفاف - PK-104»*).
2. **خوداصلاح‌گر ریاضی خطای دیداری (Math-Guided OCR):** حذف ۱۰۰٪ خطای خوانش ارقام فارسی در اسکن‌های بی‌کیفیت با حل دستگاه معادلات سطر و ستون فاکتور.
3. **خوانش اسناد خط‌خورده و دست‌نویس انبار:** نادیده گرفتن اعداد چاپی خط‌خورده و استخراج مقادیر نهایی دست‌نویس انباردار و صورتجلسه کسری/شکستگی بار.
4. **یادگیری تطبیقی کدینگ حسابداری هر شرکت:** دریافت تصویر یک نمونه سند حسابداری از هر شرکت (مثلاً کدینگ ۶ رقمی پاکشو یا ۸ رقمی افق کوروش) و تولید سند حسابداری دوبل دقیقاً با همان ساختار.
5. **۳ روش منعطف تامین اطلاعات مرجع:**
   * واکشی از دیتابیس ERP
   * استخراج خودکار جدول مرجع از روی تصویر برگه سفارش خرید با هوش مصنوعی
   * ممیزی مستقیم صورتحساب‌های جدید بدون سابقه قبلی در ERP (Ad-hoc Audit)
6. **گزارش رسمی حسابرسی A4 (PDF) و وب‌سرویس JSON استاندارد ERP.**

## وب‌سرویس‌ها (REST API Endpoints)

| متد | مسیر (Endpoint) | شرح عملکرد |
| :--- | :--- | :--- |
| `GET` | `/api/po` | دریافت لیست سفارش‌های خرید مرجع ثبت‌شده در ERP |
| `POST` | `/api/po/extract-from-image` | استخراج خودکار جدول مرجع ERP از روی تصویر برگه سفارش خرید با AI |
| `POST` | `/api/po/manual` | ثبت دستی سفارش خرید مرجع جدید در دیتابیس |
| `POST` | `/api/reconcile/{po_number}` | اجرای کامل ممیزی ۵ لایه سه‌جانبه (فاکتور + قبض انبار + سفارش خرید) |
| `POST` | `/api/reconcile-adhoc` | ممیزی مستقیم صورتحساب جدید بدون نیاز به سابقه قبلی در ERP |
| `POST` | `/api/sessions/{id}/approve-item/{sku}` | تایید معادل‌سازی کالا توسط کارشناس و ثبت دائمی در حافظه خودآموز |
| `POST` | `/api/accounting-template/{po}/learn-from-image` | یادگیری خودکار کدینگ و الگوی سند حسابداری شرکت از روی تصویر نمونه سند |

## ساختار پروژه (Project Structure)

```text
tarazban-ai/
├── Backend/
│   ├── requirements.txt
│   └── app/
│       ├── main.py          # وب‌سرویس‌های FastAPI و مدیریت جلسات ممیزی
│       ├── database.py      # مدل‌های SQLAlchemy (سفارش‌ها، حافظه خودآموز، الگوی حسابداری)

└── Frontend/
    ├── index.html
    ├── package.json
    └── src/
        └── App.jsx          # رابط کاربری مینیمال (مجهز به موتور هیبریدی Local + Cloud)
```

## راهنمای نصب و اجرای محلی (Local Setup)

### ۱. پیش‌نیاز مدل هوش مصنوعی محلی (Ollama)
```bash
ollama pull qwen3.5:4b
ollama serve
```

### ۲. راه‌اندازی بک‌اند (FastAPI)
```bash
cd Backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000
```

### ۳. راه‌اندازی فرانت‌اند (React + Vite)
```bash
cd Frontend
npm install
npm run dev
```
